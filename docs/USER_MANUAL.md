# NoEatToStop System User Manual

## システム概要
NoEatToStopは、子供の食事行動を監視し、食べるのを止めた時にTVを自動制御するスマート監視システムです。

## 初期設定

### 1. Raspberry Pi 3Bセットアップ
```bash
# セットアップスクリプトを実行
./scripts/setup-raspberry-pi.sh
```

### 2. カメラ設定
- 1080P/30fps対応USBカメラを接続
- カメラの向きを食事テーブルに調整

### 3. TV制御設定
- Panasonic TV APIまたはAlexa連携を設定
- 管理画面でTV制御方法を選択

## 管理画面の使用方法

### ダッシュボード
- システム状態の確認
- アクティブセッション数
- 今日の食事回数
- リアルタイム映像表示

### システム設定
- **停止閾値**: 食べるのを止めてからTV制御までの時間（デフォルト: 10秒）
- **信頼度閾値**: 検知の信頼度閾値（デフォルト: 80%）
- **子供の人数**: 監視対象の子供数
- **大人除外**: 大人の検知を除外するかどうか

### TV制御状態
- TV制御リクエストの履歴
- 制御成功率の確認
- エラー状況の監視

### 緊急制御
- 手動でのシステム停止
- カメラ・クラウド送信の制御

### エラー分析
- 誤検知・見逃しの報告
- システム精度の確認
- エラー統計の表示

## トラブルシューティング

### カメラが認識されない
1. USBケーブルの接続を確認
2. `lsusb`でデバイスを確認
3. カメラドライバーを再インストール

### ネットワーク接続エラー
1. Wi-Fi接続を確認
2. エッジ処理モードで継続動作
3. 接続復旧後に自動同期

### TV制御が動作しない
1. TV制御設定を確認
2. リトライ機能が動作中か確認
3. 代替制御方法（Alexa）を試行

## パフォーマンス要件
- システム応答時間: 3秒以内
- 検知精度: 80%以上
- TV制御成功率: 95%以上
- システム稼働率: 99%以上
